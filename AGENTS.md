# Sources de vérité

Le dépôt `slice-of-cactus-foundations`, attaché au même workspace,
est la source de vérité fonctionnelle et architecturale du projet.

Avant toute modification concernant :

- le modèle de contenu ;
- les taxonomies ;
- l’UX ;
- les composants ;
- les templates ;
- les relations entre contenus ;

lire les documents correspondants dans ce dépôt.

Le code doit être modifié uniquement dans `sliceofcactus-theme`.

Ne jamais modifier les Foundations sans demande explicite.
Ne jamais inventer une décision absente des Foundations.
Signaler toute contradiction ou information manquante avant d’implémenter.
